# faculty-tools Repo

Sarah's own teaching tools, served from GitHub Pages at `https://skarlis3.github.io/faculty-tools/`. Owned by the `skarlis3` GitHub account. Not a class website and not student-facing.

This is the personal side of the split: the podium app lives here and is only for Sarah. The tools she shares with colleagues live in `sk-mcc/apps` instead.

## Read these first, before doing any work in this repo

The information governing this work is deliberately not kept in this repo, because this repo is public. Nothing here repeats it, so skipping these files means working without it. **Read each one in full — do not skim for the sections that look relevant.**

1. `~/MEGA/work-with-claude-code/CLAUDE.md` — how Sarah wants the work done.
2. `~/MEGA/work-with-claude-code/work/Apps/CLAUDE.md` — these apps: what each one is, which repo it belongs in, how they publish, and the podium's calendar handling.
3. `~/MEGA/work-with-claude-code/classes/CLAUDE.md` — shared class rules. Relevant here because the podium reads the class calendars, and the calendar conventions are documented there.

Open items are tracked in `~/MEGA/work-with-claude-code/work/Apps/todo.md`.

**Anything worth writing down about these apps goes in that folder, not in this file.** This repo is public and the notes are not meant to be.
